# Series One: the sound battery

The first battery. Real clips and made files, run clean,
muted, and blacked out under one repaired question, plus the
swap matrix and the matched-level bed test.

- pegasus-receipts.md: the method and receipts for the
  Pegasus 1.6 tests, the same document as the public gist.
- receipts.md: the itemized call record behind the Pegasus
  claims.
- equal-battery.md: the definition of the equal battery,
  the identical 41 asks every open model runs.
- model-queue.md: the running order for new models.

Status: the equal battery is read for Qwen2.5-Omni-7B,
Qwen2.5-Omni-3B, and MiniCPM-o 2.6. OLA-7B is built and
waiting to run. The reads themselves live with the Series
Two diagnostics, since both batteries ran in the same
sessions.
