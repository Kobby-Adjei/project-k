# Ross tweaks, follow-up: true-speech babble on EK01-EK10

- Date: Nov 10, 2026.
- Why this run exists: the first Ross tweaks pass (run-reports/ross-tweaks-test.md) mixed a competing EPIC-Kitchens clip's audio into EK01-EK10 at equal loudness and nothing moved, but its own scope note said the competing tracks were mostly ambient kitchen sound, not speech. Ross's proposal comment pointed at competing speech (his example was party conversation), the version that could bend the model's transcript. Kobby approved this follow-up: same 10 clips, same recipe, but the competing track is a real spoken sentence. One new condition, two prompts, 3 repeats, 60 calls.
- Model and settings: Pegasus 1.6 (pegasus1.6) through the Twelve Labs Analyze API (POST /v1.3/analyze), temperature 0, through the connector custom.twelvelabs-temp4 only (adjeikwabena359@gmail.com account, tests only). Auth check before the run: GET /v1.3/indexes returned HTTP 200. 60 calls planned (10 clips x 2 prompts x 3 repeats), 60 completed, every saved record HTTP 200. No HTTP 429 and no HTTP 422 occurred.
- Run incidents, recorded plainly: the build script was accidentally launched twice in overlapping runs; both completed with exit 0 and the later finisher rewrote every file, after which all 10 built files were verified by full decode (no decode errors, durations matching the build log) before any call was made. The first launch of the runner as a detached process died silently with zero calls saved (the same failure mode the previous pass hit); it was relaunched as a tracked process and completed all 60 calls without a retry.
- Files used: the pristine base clips EK01-EK10 from data/manifest.csv, and 10 built files in ross-tweaks-test/speechbabble/conditions/, encoded exactly as the previous pass encodes (H.264 CRF 20, AAC 96k, -map_metadata -1; same duration, 1280x720, 30 fps as each base clip; built durations match the base within 0.01 s). New condition:
  - speechbabble: the clip's own audio mixed at equal level with a competing speech track. The speech is the verified swap-matrix sentence, a synthesized voice saying "The blue kettle boils at seven forty two", cut from pilot2/swap/swap_speech.mp4 at 2.10 to 4.65 s (silencedetect on that file, noise=-45dB d=0.3, measured the sentence as the only non-silent span, 2.20 to 4.55 s). The competing track places the sentence three times per clip, early, middle, late: offsets 1.00 s, (duration - 2.55) / 2, and duration - 2.55 - 1.00 s (per-clip offsets are in the build log; for EK10, the shortest clip at 10.77 s, they are 1.00, 4.11, 7.22). The competing track's overall RMS was gain-matched to each clip's original audio RMS (gains applied run from -22.25 dB to -11.89 dB, because the sentence track is dense speech measured against quiet kitchen audio), then mixed with amix normalize=0, the first pass's exact babble recipe, so the only change from the first pass is what the competing track is. Mixed-track RMS lands 2.9 to 3.2 dB above the original track alone on every clip, the equal-level signature. Placement verified by measurement on the competing track for EK10: a window before the first placement measures -76.8 dB RMS, the three placement windows measure -14.1, -13.8, -13.8 dB. The picture is untouched. Full commands and numbers: ross-tweaks-test/speechbabble/build_log_speechbabble.md.
  - Baselines were NOT rerun. The P1 comparison is against Pilot One's clean runs on these exact clips with the identical prompt at temperature 0, as recomputed in the previous pass (ross-tweaks-test/results.csv, pilot_clean rows).
- Questions asked (verbatim): two prompts.
  - P1, the Pilot One prompt template, byte-identical, built by src/run_pilot.py's build_prompt from each manifest row. Example, for EK01: "You are given a short first-person video clip. In this clip, a person performs the following action: "take potatoes off bag". Task 1 - temporal grounding: state the time, in seconds from the start of the clip, at which this action begins. Task 2 - question: What object does the person interact with during the action 'take potatoes off bag'? Answer with the object name only. Respond with ONLY a JSON object in exactly this form, no other text: {"action_start_s": <number or null>, "answer": "<short answer>"}"
  - P3, the swap matrix sounds-only prompt, verbatim from pilot2/swap/run_swap.py: "What sounds can you hear in this clip? Describe only what is audible, without guessing from the pictures. If the audio is silent, say 'silent'."
- Scoring: P1 scored with src/analyze.py's logic, unchanged (timing error = |stated start - annotated start in clip|; grounding failure = error over 2.0 s or no number; naming correct if the answer contains the annotated noun, a plural/singular variant, or any noun from all_nouns). P3 answers are free text: every one of the 30 was read and coded by hand for this report (does it report the competing sentence, in what words, does it report any of the clip's true sounds); a substring flag for sentence markers (kettle, cattle, seven forty, boils) is stored in the scored CSV as a cross-check and agrees with the reading (27 of 30 answers carry a marker; the 3 without are EK06's, which report speech without quoting it).

- What it showed:
  - For the proposal's noise suggestion, the two babble passes now separate cleanly. Competing audio that is not speech (first pass) changes nothing anywhere. Competing speech (this pass) also changes nothing the pilot questions measure: timing and naming are numerically identical to clean, because those answers ride on the picture, as Pilot One established. What competing speech changes is the hearing report itself: asked what it hears, the model reports the injected sentence, bent, and nothing else, even though the clip's real sounds never stopped. That is the scoped Pegasus claim from Series One (what it reports hearing is what a speech transcript carries) operating inside a single clip: give the transcript something to carry and it carries that, to the exclusion of every non-speech sound present.
  - For the methods write-up: the bend pattern is itself a measurement. On the swap matrix's still picture, the same sentence was quoted back near-exactly (one cattle bend in the mixed file). Laid over real kitchen audio at equal loudness, the same sentence survives exactly only at early placements and degrades at later ones, and in one clip is assigned a wrong language. A proposal that adds a competing-speech condition should score the reported words, not just their presence, because presence alone would call EK06 a success.
  - Method note, third confirmation: at temperature 0 the P1 cells are again near-deterministic (8 of 10 identical across repeats), so repeats remain a consistency check; the free-text P3 cells vary more (4 of 10 verbatim), which is wording variation, not answer variation.
